# 05: Arquivar e restaurar listas pelo histórico

**What to build:** O usuário local consegue arquivar manualmente listas ativas, consultar o histórico, restaurar uma lista preservando seu estado exato ou excluí-la permanentemente com confirmação; listas arquivadas ficam somente para consulta.

**Blocked by:** 03 — Adicionar e acompanhar itens comprados.

**Status:** done

- [x] A lista pode ser arquivada por uma ação manual explícita.
- [x] O arquivamento de uma lista com itens pendentes pede confirmação e não ocorre automaticamente.
- [x] A lista arquivada deixa de aparecer entre as ativas e aparece no histórico por recência de arquivamento.
- [x] O usuário consegue abrir uma lista arquivada em modo somente leitura.
- [x] O usuário consegue restaurar a lista e recupera nome, itens, ordem, preços, quantidades, unidades e marcações.
- [x] Uma lista restaurada volta às listas ativas e pode ser editada.
- [x] O usuário consegue excluir permanentemente uma lista arquivada após confirmação explícita.
- [x] O ciclo de vida de arquivamento, consulta, restauração e exclusão é testado no módulo de regras das listas.
