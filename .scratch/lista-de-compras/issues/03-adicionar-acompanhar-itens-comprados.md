# 03: Adicionar e acompanhar itens comprados

**What to build:** Dentro de uma lista ativa, o usuário local consegue adicionar e editar itens, manter itens com nomes repetidos, marcar e desmarcar itens comprados e remover itens com confirmação, preservando a ordem de inclusão.

**Blocked by:** 02 — Criar e gerenciar listas ativas.

**Status:** done

- [x] O usuário consegue adicionar um item com nome obrigatório a uma lista ativa.
- [x] Nomes de itens repetidos são aceitos como entradas independentes.
- [x] O usuário consegue editar o nome de um item e recebe erro para nome vazio.
- [x] O usuário consegue marcar e desmarcar um item comprado sem removê-lo da lista.
- [x] Itens comprados permanecem visíveis por padrão e são diferenciados visualmente.
- [x] O usuário consegue ocultar e mostrar itens comprados.
- [x] O usuário consegue remover um item após confirmação explícita.
- [x] A ordem de inclusão dos itens permanece estável após edição ou desmarcação.
- [x] As operações são persistidas e cobertas por testes no módulo de regras das listas.
