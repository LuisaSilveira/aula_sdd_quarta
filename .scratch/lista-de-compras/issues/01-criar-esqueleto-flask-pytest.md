# 01: Criar esqueleto Flask e pytest

**What to build:** Uma aplicação Flask mínima que abre no navegador com uma página inicial vazia, acompanhada por um teste pytest passando, para que o restante do produto possa evoluir sobre uma base executável.

**Blocked by:** None (can start immediately).

**Status:** done

- [x] A aplicação Flask inicia pelo ponto de entrada definido para o app e renderiza a página inicial vazia.
- [x] As dependências mínimas de execução e teste estão declaradas em `app/requirements.txt`.
- [x] Existe pelo menos um teste pytest que executa e passa contra a aplicação mínima.
- [x] A estrutura inicial separa a entrada Flask da futura camada de regras das listas.
