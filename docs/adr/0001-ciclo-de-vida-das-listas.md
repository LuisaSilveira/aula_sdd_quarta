# Ciclo de vida das listas

Listas concluídas serão arquivadas manualmente, preservando itens, preços e marcações, em vez de serem excluídas ou arquivadas automaticamente. O histórico permitirá consultar, restaurar ou excluir permanentemente uma lista; enquanto arquivada, ela será somente leitura. Essa separação mantém compras recorrentes recuperáveis e evita esconder alterações atrás de automações.

## Consequências

- Uma lista pode ser arquivada mesmo com itens pendentes, mediante confirmação.
- Restaurar uma lista retorna exatamente seu estado anterior para as listas ativas.
- Edições exigem restauração, mantendo um único caminho de edição.
